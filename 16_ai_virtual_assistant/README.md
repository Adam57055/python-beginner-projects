AI Powered Virtual Assistant – "Sam"

An AI-powered command-line virtual assistant built using Python and OpenAI's API.
Sam can hold conversations by maintaining chat history and responding intelligently to user input.

This project demonstrates:

OpenAI API integration

Chat-based interaction

Message history management

Continuous CLI loop

Basic AI assistant architecture

🚀 Features

Interactive command-line chat

Maintains conversation context

Uses OpenAI's GPT model for responses

Runs continuously until manually stopped

🛠️ Technologies Used

Python 3.9+

OpenAI Python SDK

GPT model (gpt-5o)

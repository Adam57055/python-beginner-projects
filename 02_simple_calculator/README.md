Simple Calculator (CLI Based)

A beginner-friendly Python project that performs basic arithmetic operations using functions and a command-line interface.

This project demonstrates:
Functions
Loops
Conditional logic
Match-case statement (Python 3.10+)
User input handling
f-strings for formatted output

##🚀 Features

Addition
Subtraction
Multiplication
Division
Division by zero handling
Continuous execution using a loop
Exit option to stop the program

🛠️ Technologies Used

Python 3.10 or above (required for match-case)
No external libraries required

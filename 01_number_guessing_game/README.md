# 🎯 Number Guessing Game

## 📌 Description
A simple CLI-based game where the user tries to guess a randomly generated number within a given range.

## 🚀 Features
- Random number generation
- User input handling
- Hint system (Too high / Too low)
- Loop until correct guess

## 🧠 Concepts Used
- `random` module
- Loops (`while`)
- Conditional statements
- Input validation
